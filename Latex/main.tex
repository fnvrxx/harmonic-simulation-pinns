\section{Pengertian PINNs}
\textit{Physics-Informed Neural Networks} (PINNs) merupakan gabungan Neural Networks dengan menggabungkan hukum fisika yang di deskripsikan dengan persamaan diferensial ke dalam fungsi loss untuk proses pelatihan ke arah solusi yang lebih akurat dengan mendasari hukum fisika yang berlaku \cite{matlab}. PINNs bisa digunakan untuk :
\begin{itemize}
    \item Pendekatan solusi untuk persamaan diferensial biasa (PDB) dan persamaan diferensial parsial (PDP)
    \item Menyelesikan \textit{inverse problems}, seperti estimasi parameter model dari data yang terbatas
\end{itemize}

\section{Problem Overview}
\subsection{Oscillator Harmonik Teredam}
Kita akan menyelesaikan masalah oscilator harmonik teredam dengan menggunakan PINNs:

Ini merupakan masalah fisika, yang dimana perpindahan $u(t)$ merupakan fungsi dari waktu oscillator yang bisa kita deskripsikan dengan persamaan diferensial :
\begin{equation}
    m \frac{d^2u}{dt^2} + \mu \frac{du}{dt} + ku = 0
\end{equation}
dimana $m$ adalah massa, $\mu$ adalah koefisien redaman, dan $k$ adalah konstanta pegas. Kita akan fokus menyelesaikan masalah ini di "under-damped state", yang dimana osilasi menjadi pelan seiring waktu (seperti gambar di atas).\\

Secara matematis, keadaan tersebut bisa ditulis:
\begin{equation}
    \delta < \omega_o, \ dimana \ \delta = \frac{\mu} {2m}, \ \omega_o = \sqrt{\frac{k}{m}}
\end{equation}
Terlebih lagi, kita memikirkan dengan mengikuti kondisi awal dengan sistem:\\
\begin{equation}
    u(t = 0) = 1, \ \frac{du}{dt}(t = 0) = 0.
\end{equation}
Untuk kasus ini, kita menggunakan exact solusi yang diberikan oleh:
\begin{equation}
    u(t) = e^{-\delta t}(2A \cos(\phi + \omega t)), \quad \omega = \sqrt{\omega_o^2 - \delta^2}
\end{equation}
Untuk lebih detail matematis terkait osilator harmonik teredam, dapat dilihat melalui \cite{beltoforion}.

\subsection{Workflow overview}
Untuk menyelesaikan masalah oscilator harmonik teredam dengan menggunakan PINNs, kita akan mengikuti workflow berikut:
\begin{enumerate}
    \item Membuat Neural Network 
    \item Melatih Neural Network dengan opsimasi L-BFGS dan Levenberg-Marquadt
    \item Membuat loss function yang menggabungkan persamaan diferensial dan kondisi awal menggunakan ansatz (hard constraint) untuk memastikan bahwa solusi yang dihasilkan oleh PINNs memenuhi kondisi awal
    \item Membuat gradien dari loss function dengan menggunakan automatic differentiation untuk menghitung turunan yang diperlukan dalam persamaan diferensial (seperti $\frac{du}{dt}$ dan $\frac{d^2u}{dt^2}$)
    \item Melakukan optimasi untuk meminimalkan loss function dengan menggunakan algoritma optimasi seperti L-BFGS atau Levenberg-Marquadt untuk memperbarui parameter dari PINNs
    \item Mengevaluasi performa PINNs dengan membandingkan solusi yang dihasilkan dengan solusi eksak dan menghitung error untuk menilai akurasi dari PINNs
\end{enumerate}
